# NPU Offload Pipeline

Read these project references before changing NPU kernels or model engines:

1. `../npu_offload_pipeline.md` contains the full proven EmbeddingGemma
   compilation, XRT integration, validation, troubleshooting, and binary
   inventory workflow.
2. `../../../docs/precompiled_replacement_map.md` maps every shipping binary
   category to an open replacement and defines architecture/shape bundles.
3. `../../../docs/precompiled_artifacts.json` is the machine-readable shipping
   inventory generated by `../../../utilities/binary-inventory/inventory.py`.
4. `../../../REPLACEMENT_PLAN.md` records the long-term family order and design
   decisions.

Required rules:

- Put reusable binary/XCLBIN investigation tools under `utilities/`.
- Extend `utilities/q4nx-build` for model builders; do not create a parallel
  converter.
- Distribute XCLBINs by architecture and tensor shape, not fine-tune name.
- Validate CPU and NPU outputs before removing an existing family binary.
- If closed behavior is not reproduced, return an explicit `not implemented`
  error rather than silently depending on the closed component.
- After compiling new XCLBINs or libraries, record exact commands, toolchain
  versions, shapes, hashes, and validation results in a new or updated skill.
