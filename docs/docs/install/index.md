# ⬇️ Install OpenFlowLM

OpenFlowLM needs an **AMD Ryzen™ AI NPU with XDNA2** -- Strix, Strix Halo,
Kraken Point or Gorgon Point. Ryzen AI 7000 / 8000 / 200-series chips have
XDNA1 and are **not** supported. No discrete GPU is required.

Pick your platform:

| Platform | Guide | Package |
|---|---|---|
| **Windows** | [Get Started (Windows)](/docs/install_win/) | `.msi` |
| **Linux** | [Get Started (Linux)](/docs/install_lin/) | `.deb`, `.rpm`, `.tar.gz` |

All packages come from the
[GitHub Releases page](https://github.com/Atomic-Germ/OpenFlowLM/releases).
The Linux page also covers building from source with the CMake presets.

> ℹ️ Looking for the quick path? On Linux, the
> [Linux getting-started guide](/linux-getting-started/) is the condensed
> version of `/docs/install_lin/`.
