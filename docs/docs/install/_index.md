OpenFlowLM runs local chat, vision, embeddings, speech, and image generation workloads on **Windows & Linux** using AMD Ryzen AI processors with an XDNA2 NPU, with no discrete GPU required.

Verify your processor and memory in [Hardware & Quickstart](/docs/install/requirements/), then choose your operating system below.

## Choose Your Operating System

| Operating System | Setup Guides | Installation Methods |
|---|---|---|
| **Windows** | [Windows](/docs/install/windows/) | Windows 11 (`x64`) `oflm-setup.msi` installer with AMD Ryzen AI NPU driver `32.0.203.304+` |
| **Linux** | [Linux Overview](/docs/install/linux/) · [Packages](/docs/install/linux/packages/) · [Docker](/docs/install/linux/docker/) · [Nix & NixOS](/docs/install/linux/nix/) | Ubuntu `.deb`, Fedora `.rpm`, portable `.tar.gz`, Docker, Nix flake, and NixOS module |

> [!TIP]
> Download prebuilt installers and release archives from [GitHub Releases](https://github.com/Atomic-Germ/OpenFlowLM-Next/releases). Contributors compiling from source can see [Build System](/docs/contributing/build/).
